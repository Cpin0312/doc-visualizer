# DocVisualizer（資料を図にする）

Copilot などがまとめた md ファイルを選ぶだけで、流れ・日程・表などの図にします。PDF と PowerPoint でも出せます。

- **サーバーもネットも使いません。HTML 1枚（`dist/DocVisualizer.html`）をダブルクリックで開くだけです。** インストールも要りません。
- **完全オフライン**：中身はブラウザの中だけで読みます。外へは何も送らず、何も読みこみません（CSP で止めています）。ブラウザにも残しません。
- 無料の部品だけでできています（three.js・PptxGenJS。どちらも MIT）。

## 使い方（Windows）

1. `dist/DocVisualizer.html` を手元に置きます（GitHub の画面で開き、「Download raw file」で保存）。
2. 保存したファイルをダブルクリックして、**Edge** か **Chrome** で開きます。
   - 別のアプリで開くときは、右クリック →「プログラムから開く」→ Microsoft Edge。
3. 「md を選ぶ」を押して md ファイルを選びます（画面にドラッグ＆ドロップでもよい）。
4. まずは「見本を開く」で試せます。7種類の図・印・出どころ・本文が全部入った例は [`examples/全部入りの例.md`](examples/全部入りの例.md) です（中身は作り話）。

Mac でも同じです（Chrome か Edge。Safari・Firefox は試していません）。

画面でできること：

- 箱を押すと、説明と出どころが横に出ます。もう1回押すと閉じます。
- 「3D にする / 2D にする」で、立体の図と平らな図を切りかえます。3D はドラッグで回り、2回押すと元の向きに戻ります。
- 「小・中・大」で文字の大きさを変えます。大きな図は縮めすぎず、横に動かして見ます（文字は 11px より小さくしません）。
- 「発表」（または P キー）で、図と箱を1つずつ大きく見せます。→・スペースで次、← で前、Esc で終わります。

## md の書き方

1行目に題名、そのあとに「ひとことで・結論・すること」を書きます。図はコードブロックの1行目に「種類 図の名前」を書きます。

````md
# 題名
> ひとことで：…
> 結論：…
> すること：…
> 社外秘：社外秘

```flow 注文の流れ
受付 -> 確認 -> 見積
見積 -> 承認 : OK
見積 -> 受付 : 差し戻し
承認 !期限
```

## 受付
箱の説明はここに書く。
[元：注文の手順 2ページ]
````

| 種類 | いつ使う | 書き方 |
|---|---|---|
| flow | 手順・流れ | `受付 -> 確認`、矢印の言葉は `見積 -> 承認 : OK` |
| lanes | 担当ごとの流れ | `[営業] 受付 -> [経理] 請求` |
| timeline | 日程・期限 | `2026-12-01 説明会`、期間は `2026-12-07〜2026-12-18 試行` |
| tree | 分けかた・組織 | 字下げ（スペース2つ）と `-` |
| chart | 数字の比べ | `4月 : 120`、単位は図の名前の後ろに `（件）` |
| kpi | 大事な数字 | `売上 : 1,200万円 : 前年比 +8%` |
| compare | 案の比べ | 表（`\|` 区切り）。◎○ よい・△ まあまあ・× よくない |

- 印：`!期限` `!問題`（赤）、`?確認`（黄）、`+完了`（緑）。
- flow・lanes で矢印のない行は、箱を1つ置くときだけに使います（名前と印だけ）。文の行は図にせず、知らせに出します。
- 全角の記号（→ ： ［］）、Shift_JIS・EUC-JP のファイル、CRLF の改行も読めます。読めなかった行は、行番号つきで「読みとりの知らせ」に出ます。

## Copilot の指示文の使い方

1. 画面の「Copilot 用の指示をコピー」を押します（中身は `copilot-prompt.md` と同じ）。
2. Copilot に貼り、続けて職場の資料を渡します。
3. Copilot が出した md を保存して、この画面で選びます。外側が ```markdown で包まれていても、そのまま読めます。

## 会社の PC で 3D が出ないとき

WebGL（3D の描き手）が止められている PC では、自動で 2D になり、画面の上に理由を1行出します。2D・PDF・PowerPoint はそのまま使えます（3D の絵のページはなくなります）。

## PDF の出し方

1. 「PDF」を押します。
2. 印刷の窓で、送り先を **「PDF に保存」**、用紙を **「A4・横」** にして保存します。
   - 色が出ないときは、印刷の窓の「詳細設定」→「背景のグラフィック」を入れます。

表紙・図ごとのページ（2D と 3D の絵）・箱の説明と出どころ・本文が入り、全ページに社外秘の印とページ番号がつきます。

## PowerPoint（.pptx）

「PowerPoint」を押すと、`<題名>.pptx` を作ってダウンロードに渡します（ふつうはダウンロードの場所に保存されます）。図は、あとで直せる図形と文字です。大きな図はスライドを分けます。字体は Yu Gothic UI です。

**保存できないとき**：ダウンロードの一覧に出ないときは、会社の設定で止められています（ブラウザは止めたことを画面に知らせないので、この画面からは分かりません）。そのときは「PDF」で出してください。作る途中で失敗したときは、画面の上に赤い帯で理由が出ます。

## 作り直し方

node.js（20 以上）が要ります。

```bash
npm ci
```

```bash
npm run build
```

`src/` を直したら `npm run build` で `dist/DocVisualizer.html` を作り直します。

## 試験

```bash
npm test
```

- 作り直したあと、`test/run.mjs` を回します（作り直さずに試すときは `npm run test:only`）。画面の試験は Chrome か Edge を探して、`file://` で開き、本物のファイル選び・クリック・印刷（PDF）で確かめます。
- ブラウザの場所は `CHROME_PATH` か `EDGE_PATH` で渡せます（なければ OS ごとの決まった場所を探します）。
- PowerPoint の試験は python-pptx で読み返します：`pip install --user python-pptx`
- 結果は `test/out/`（画面の絵・PDF・pptx・result.json）。
- GitHub Actions（`.github/workflows/windows.yml`）で、Windows（Edge）と Mac（Chrome）でも回します。
