# 注文を受けてから送るまで（架空の例）
> ひとことで：注文は「受付 → 確認 → 見積 → 承認 → 発送」の5つで進む
> 結論：見積は3日以内に出す。承認は課長まで
> すること：差し戻しの理由を毎回書きのこす
> 社外秘：社外秘

```flow 注文の流れ
受付 -> 確認 -> 見積
見積 -> 承認 : OK
見積 -> 受付 : 差し戻し
承認 -> 発送 +完了
承認 !期限
確認 ?在庫
```

## 受付
お客様から電話かメールで受ける。受けた日を台帳に書く。
[元：注文の手順（架空）2ページ]

## 見積
在庫と値段を見て、3日以内に出す。
- 値引きは 5% まで
- それより大きい値引きは課長に相談
[元：注文の手順（架空）4ページ]

## 承認
課長が見て OK を出す。期限は見積から2日。
