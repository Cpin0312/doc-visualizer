# フローチャートの試験（作り話）
> ひとことで：5つの形
> 社外秘：試験用・社外秘

```flowchart 判断が2つ（在庫と金額）
(開始) -> /注文を受ける/ -> <在庫ある?>
<在庫ある?> -> <10万円をこえる?> : はい
<在庫ある?> -> [[発注する]] : いいえ
[[発注する]] -> 在庫を入れる -> 注文を受ける
<10万円をこえる?> -> 部長が承認 : はい
<10万円をこえる?> -> 出荷する : いいえ
部長が承認 -> 出荷する
出荷する -> (終わり)
```

```フローチャート 判断が3つに分かれる
(開始) -> <種類は?>
<種類は?> -> 見積 : 新規
<種類は?> -> 契約 : 更新
<種類は?> -> 解約 : 解約
見積 -> (終わり)
契約 -> (終わり)
解約 -> (終わり)
```

```flowchart 戻る矢印が何本も
(開始) -> 受付 -> 確認 -> 承認 -> (終わり)
確認 -> 受付 : 不備
承認 -> 確認 : 差し戻し
承認 -> 受付 : 最初から
```

```flowchart 輪と同じ名前
(開始) -> A -> B -> C -> A
B -> B
<A> -> D
A -> D
形を付けない同じ名前 -> 形を付けない同じ名前
```

```flowchart 長い名前と全部の形
(長い名前のはじめでありえないほど長いはじめの名前です) -> /長い入力の名前でとても長く折り返される入力/ -> 処理 -> <判断が長い名前でとても長く折り返される判断は?> : はい
<判断が長い名前でとても長く折り返される判断は?> -> [[別の手順の名前も長い長い長い手順]] : いいえ
[[別の手順の名前も長い長い長い手順]] -> (終わり)
```
